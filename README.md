# Delhi NCR Sales Performance Dashboard

## 📊 Project Overview

This project presents an interactive Sales Performance Dashboard created using Microsoft Excel.

The dashboard analyzes sales performance across different months, categories, regions, sales channels, customer segments, and order statuses.

## 🎯 Objective

The objective of this project is to transform raw sales data into meaningful business insights using Excel data analysis and visualization techniques.

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- KPI Development
- Business Insights

## 📈 Dashboard KPIs

- Total Sales: ₹47,33,78,289.12
- Total Quantity: 90,129
- Total Orders: 30,000
- Total Profit: ₹14,90,09,545.59
- Average Order Value: ₹15,779.28
- Profit Margin: 31.48%

## 📊 Dashboard Analysis

The dashboard includes:

- Monthly Sales Trend
- Category-Wise Sales
- Region-Wise Sales
- Profit by Category
- Sales Channel Analysis
- Order Status Analysis
- Sales by Customer Segment

## 🔍 Key Insights

- Electronics is the top-performing sales category.
- Noida is the leading region by sales.
- January 2026 is highlighted as the top sales month.
- The Store channel shows strong sales performance.
- The Consumer segment contributes the highest sales among customer segments.
- Delivered orders represent the largest share of order status.
